# 🏰 Enchanted Castle Adventure

This is my "Checkpoint" project for *The Legend of Python* course. It is an interactive text-based adventure game that runs directly in the terminal.

## 📝 Game Description
In this mini-game, the player wakes up in the Great Hall of a dark castle. The objective is to explore different rooms, make strategic decisions, and find the Golden Key to escape alive before losing all health points (HP).

## 🛠️ Python Concepts Applied
To build this game, I applied the following programming fundamentals:
* **Variables:** To keep track of the player's health (`hp`) and inventory (`has_key`).
* **Control Flow (`if/elif/else`):** To create multiple story branches depending on the player's choices.
* **Loops (`while`):** To keep the game running continuously until the win or lose condition is met.
